## Android color palettes

The Android theme definitions adapt color values from these upstream palettes:
Catppuccin, Nord, Rosé Pine, Gruvbox, Dracula, Solarized, Tokyo Night,
Kanagawa, and Everforest. Each source file links to its upstream palette.

- https://github.com/catppuccin/palette
- https://www.nordtheme.com/docs/colors-and-palettes
- https://rosepinetheme.com/palette/
- https://github.com/morhetz/gruvbox
- https://draculatheme.com/spec
- https://ethanschoonover.com/solarized/
- https://github.com/folke/tokyonight.nvim
- https://github.com/rebelot/kanagawa.nvim
- https://github.com/sainnhe/everforest/blob/master/palette.md
